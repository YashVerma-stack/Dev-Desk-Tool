1. Issue Status
Status	Meaning
open	Newly created issue that hasn't been started.
in_progress	Someone is currently working on the issue.
resolved	The issue has been fixed.
closed	The issue is completed and no further work is required.

2. Issue Priority
Priority	Meaning
critical	Very serious issue requiring immediate attention.
high	Important issue that should be fixed soon.
medium	Normal issue with moderate importance.
low	Minor issue that can be handled later.
